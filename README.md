# かんたんミニマップメーカー (Easy Minimap Maker - GPS-Free Route Animator)

街歩き動画や車載動画・ツーリング動画などで活用できる、OpenStreetMapを用いた現在地マップ動画素材（クロマキー合成用）をブラウザ完結で手軽に作成できるWebアプリケーションです。  
GPSロガー等の専用機器や位置情報ログがなくても、動画を見ながら交差点や曲がり角で地図をタップするだけで移動ルートと現在地を自動線形補間。信号待ちや立ち止まり区間の設定、横長タイムラインでの精密なキーフレーム編集、720×720の縮尺スケール付きクロマキー動画（Adobe Premiere等のUltraキー用）やGPX/GeoJSONデータの一括エクスポートに対応しています。

- **Webアプリ**: [https://nyaftama.github.io/easy-minimap-maker/](https://nyaftama.github.io/easy-minimap-maker/)
- **作者**: [@nyaftama](https://nyaftama.github.io/)

## 主な機能

1. **GPSログ不要・地図タップで直感ルート作成**
   - GPSトラッカーや位置情報データがなくても、動画を見ながら地図上の交差点や曲がり角をタップするだけでルートを構築
   - キーフレーム間の緯度・経度・縮尺を滑らかな線形補間で自動計算
   - 地図上のピンの直接ドラッグによる位置微調整、および現在時刻への地点コピー追加機能
   - 開始地点「#S」から始まる直感的な地点通し番号（#S, #1, #2...）の自動付与
   - マップ上のルート軌跡（全ルートおよび通過済みルート）のリアルタイム描画

2. **キーワード・URL・座標のハイブリッド地図検索**
   - 地図上の検索バーから、駅名・地名・住所・施設名・交差点をインクリメンタル検索
   - 国土地理院 ジオコーダー API と OSM Photon API のハイブリッド検索により国内から海外まで幅広く網羅
   - Googleマップの共有URLや「35.6812, 139.7671」等の緯度経度テキストの直接貼り付けにも対応

3. **信号待ち・立ち止まりの「一時停止」区間対応**
   - キーフレームを選択して「一時停止を開始」→動画を進めて「一時停止を終了」するだけで、動画が流れていても現在地がその場に留まる信号待ちや立ち寄り区間を自然に定義
   - 一時停止作成中の誤操作を防ぐタイムライン一括操作ロック & 自動保存の整合性保護
   - 開始地点と終了地点（#S'や#1'）の地点座標・通し番号の自動同期
   - **スマート削除連携**: 開始地点を削除した場合は終了地点も連動して削除、終了地点のみを削除した場合は開始地点を通常の単一キーフレームへ安全に復旧

4. **動画編集ソフト風 横長タイムラインエディタ**
   - 時間ルーラー、再生ヘッド、キーフレームマーカーを俯瞰できる本格的な横長タイムライン
   - 4種類の選択ツール（単一選択、前方選択、後方選択、矩形範囲選択）による自由自在なキーフレーム選択
   - 選択キーフレームの一括時間移動（左右ドラッグシフト）
   - キーボード操作（Space: 再生/停止、←/→: ±1f移動、Shift+←/→: ±1s移動、↑/↓: 前後キーフレーム移動、Del: 削除）
   - 2本指ピンチ操作およびスライダーによるタイムライン拡大縮小
   - スマートフォンなどのタッチ端末に最適化されたボタン挙動

5. **10世代の取り消し・やり直し（Undo / Redo）**
   - キーフレームの追加・移動・削除・地点変更など、すべての編集操作を最大10世代まで履歴管理
   - ショートカットキー（Ctrl/Cmd+Z, Ctrl+Y / Shift+Cmd+Z）およびツールバーボタンによる即座の復元

6. **動画編集用クロマキー素材出力 ＆ 一括ZIPエクスポート**
   - Adobe Premiere等のUltraキーで即座に背景透過できる720×720 正方形のクロマキー動画（グリーンバック／ブルーバック／マゼンタ／ブラック）
   - プリセット（ブルー／レッド／オレンジ／グリーン／パープル／ダークネイビー）およびカラーピッカーによる現在地マーカー色のカスタマイズ
   - タイムライン・マップと同様の通し番号付き菱形ピンの動画内オーバーレイ描画（オン/オフ対応）
   - 地図縮尺倍率の拡大選択（100% / 150% / 200%）による、地名・道路名・縮尺マーカーの鮮明な表示
   - ワイプ形状のカスタマイズ（正方形・角丸正方形・円形サークルワイプ）
   - 緯度と地図スケールに連動して正確な距離を示す縮尺スケールバー（メートル／キロメートル）の自動描画
   - WebCodecs（VideoEncoder + mp4-muxer）によるブラウザ上での高速MP4エンコード（非対応環境向けMediaRecorderフォールバック搭載）
   - 再編集用プロジェクトJSON、GPXファイル、GeoJSONファイル、READMEテキストをまとめたZIP一括ダウンロード

7. **完全ローカル処理 ＆ 自動保存・クラッシュ復元**
   - 動画ファイルや位置情報データはすべてブラウザ内（端末内）で処理され、サーバー等への外部アップロードは一切なし
   - LocalStorageへの即時・定期自動保存によるクラッシュ保護

## 使い方

1. **動画を準備・読み込む**
   - 街歩きやドライブ、ツーリング等の元動画（MP4, MOV, WebM）をスタート画面にドラッグ＆ドロップまたはファイル選択で読み込みます。動画ファイル名が自動的にプロジェクト名の初期値として設定されます。

2. **動画を見ながら地図上にキーフレームを打つ**
   - 動画を再生またはジョグスクラバーで進めながら、曲がり角や交差点などの通過ポイントで地図上をタップ/クリックしてキーフレームを追加します。
   - 目的地の検索バーに地名やGoogleマップURLを入力して候補を選択すると、ピンが立ち素早く位置を特定できます。

3. **信号待ちなどの一時停止区間を設定する**
   - 赤信号や立ち寄りの地点となるキーフレームを選択し、タイムライン上部の「一時停止を開始」をタップ。
   - 動画を進めて動き出したタイミングで「一時停止を終了」をタップすると、現在地が静止する区間が作成されます。

4. **タイムラインで微調整・確認する**
   - タイムライン上でキーフレームの位置や時間を微調整します。必要に応じてピンのドラッグや前後移動ボタン（↑/↓）、Undo/Redoを活用します。

5. **クロマキー動画・データをエクスポートする**
   - ヘッダーの「エクスポート」ボタンをタップし、地図スケール（200%/150%/100%）、クロマキー色、ワイプ形状（円形・正方形）を選択して「エクスポート開始」を実行。
   - 生成されたMP4動画やGPX/GeoJSON/JSONデータをまとめたZIPファイルをダウンロードします。

## 更新履歴

- **v0.92** (2026/09/07)
  - **ズームレベル設定 & 縮尺固定化**: キーフレームごとの縮尺差によるタイル欠落を防ぐため固定ズームに対応。エクスポート時にズームレベル（14〜18）を選択可能とし、デフォルトで編集画面の現在の地図ズームを自動反映。
  - **ズーム変更時のタイル高速並行読み込み**: ルート移動軌跡に沿った時間サンプリングによる過不足のないタイル抽出、同時4並行ダウンロード、および最大2回の自動リトライ（指数バックオフ）を導入し、タイル欠落（グレー背景化）を解消。
  - **マップピン & 動画内ピンの菱形化**: 編集画面のキーフレームピンをしずく型から菱形へ変更。さらにエクスポート動画内への通過地点ピン描画機能（オン/オフ可能）を追加。

- **v0.91** (2026/09/07)
  - **地図検索機能**: 国土地理院API、OSM Photon API、GoogleマップURL/緯度経度テキストによるハイブリッド検索機能を追加。
  - **エクスポート地図スケール**: 書き出し時の地図スケール選択（100%/150%/200%、デフォルト200%）を追加し、動画内での地名や縮尺マーカーの視認性を向上。
  - **一時停止ワークフロー刷新**: 選択キーフレームからの一時停止開始、作成中の一括操作ロック・自動保存保護、開始/終了の連動削除に対応。
  - **通し番号体系の改善**: 1番目を「#S」（Start）、2つ目以降を「#1, #2...」と直感的な連番に変更。
  - **モバイルUI最適化**: スマホ表示でのボタンのコンパクト化、タッチ後の:active/:focus状態残留の防止。
